=== The MongoDB password reaches the processor as a mounted file, not as an environment variable ===

$ kubectl exec <processor pod> -- ls -lnL /etc/secrets/mongo
total 8
-r--r----- 1 0 1000 45 Oct 14 16:06 password
-r--r----- 1 0 1000  8 Oct 14 16:06 username

$ kubectl exec <processor pod> -- env     (only the variables whose name starts with MONGO_USER or MONGO_PASSWORD)
MONGO_PASSWORD_FILE=/etc/secrets/mongo/password
MONGO_USER_FILE=/etc/secrets/mongo/username

=== The pod has no token for the Kubernetes API: it cannot ask the cluster for anything ===

$ kubectl exec <processor pod> -- ls /var/run/secrets/kubernetes.io/serviceaccount
ls: cannot access '/var/run/secrets/kubernetes.io/serviceaccount': No such file or directory
command terminated with exit code 2
