=== The five questions of make rbac-check ===
pipeline-viewer   can list pods?       yes
pipeline-viewer   can delete pods?     no
pipeline-operator can scale producers? yes
pipeline-operator can read secrets?    no
processor pod     can read secrets?    no

=== The same rules as real requests: kubectl --as=<account> sends the request as that account ===
(--dry-run=server makes the cluster check the request, permissions included, without changing anything)

$ kubectl -n ca2 get pods --as=system:serviceaccount:ca2:pipeline-viewer

$ kubectl -n ca2 delete pod kafka-0 --dry-run=server --as=system:serviceaccount:ca2:pipeline-viewer
Error from server (Forbidden): pods "kafka-0" is forbidden: User "system:serviceaccount:ca2:pipeline-viewer" cannot delete resource "pods" in API group "" in the namespace "ca2"

$ kubectl -n ca2 scale deployment/processor --replicas=2 --dry-run=server --as=system:serviceaccount:ca2:pipeline-viewer
