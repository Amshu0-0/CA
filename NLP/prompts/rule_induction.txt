### USER

$examples

Write general rules that explain these labels, so that someone could label NEW log messages using only your rules.

- Every rule must list one or more short keyword phrases, copied exactly from the logs above, whose presence triggers the rule.
- A keyword phrase must not appear in any log of the opposite label above.

- Write at most $max_rules rules, covering both labels.

Answer with a single JSON object and nothing else, in this format:
{"rules": [{"rule": "<one sentence>", "keywords": ["<phrase>", "..."], "label": "abnormal" or "normal"}]}
